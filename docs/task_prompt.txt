Map every target object instance in this simulated scene. First call list_entities to receive the complete entity library. Estimate the geometric center of each object's rendered geometry in meters, in the ORIGINAL camera frame: origin at the camera's initial position, +x its initial optical forward, +y its initial left, +z its initial up. Camera pose tools return transforms in this same frame. Use multiple images and camera poses. For objects seen from two different camera positions, mark the same visual center pixel in each frame and use triangulate_observations before submitting its returned xyz_m. Only submit a position when you have visual evidence; do not invent locations for occluded items. The library includes equivalence groups. IDs within the same group are interchangeable for scoring, so submit one distinct valid ID per observed instance without worrying about their order. Start submitting visible objects after the first two views, then update and add estimates as you explore. Submit estimates in batches using submit_positions, then call finish_mapping. The architectural stage mesh and robot are outside the target library; some furniture and fixtures are separate target instances. Do not assume every visible object belongs to the library. This benchmark keeps only a selected subset of targets visible; map only IDs returned by list_entities.
